What is this project? (60-second version)

When you ask an AI to write code, the code often works but contains security holes. LeBlanc wraps any AI model in a safety loop and measures whether that loop is still worth anything now that models have improved — and catches the loop lying (code that passes the security scanner but no longer works).

Engine AReads your request, detects risky topics via lexical + TF-IDF retrieval over a CWE corpus, injects warnings
→
LLMGenerates the code (6 models, 3 generations: G1 old G2 mid G3 current)
→
Engine BTwo independent security scanners (Bandit ∪ Semgrep) inspect the code
→
Engine CFindings go back to the model: “fix these” — up to 3 rounds
→
Engine DFunctional tests check the “fixed” code still actually works

Three modes are compared per prompt: plain (no help), enriched (Engine A only), enriched_repair (full loop). Differences between modes across model generations = the research result.

Experiment progress

The five questions we answer

  1. RQ1 — How insecure is each model generation out of the box?
  2. RQ2 — Does warning the model up-front (enrichment) still help?
  3. RQ3 — Does the repair loop converge, and how fast?
  4. RQ4 — Which vulnerability types still survive everything, in 2026 models?
  5. RQ5 — How often is “successfully repaired” code secretly broken? (headline)

Full definitions with hypotheses & statistics live in docs/01_RESEARCH_QUESTIONS.md — the Research tab shows each formula next to its live numbers.
